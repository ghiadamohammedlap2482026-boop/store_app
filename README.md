**Nova – Responsive Electronics Store_app**

Nova is a modern, responsive electronics storefront built with HTML5, CSS3, Bootstrap 5, and JavaScript. It allows users to browse electronic products and accessories, explore product categories, search for items, manage favorites, and interact with a shopping cart.

The project focuses on responsive design, intuitive navigation, and a clean user interface, providing a smooth browsing experience across desktop, tablet, and mobile devices.

**Technologies Used:** HTML5, CSS3, Bootstrap 5, JavaScript, Bootstrap Icons, and Google Fonts.
