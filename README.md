# Nova – Responsive Electronics Store

A modern, responsive electronics store built with HTML5, CSS3, Bootstrap 5, and JavaScript. Features product browsing, category filtering, search, favorites, and an interactive shopping cart.

**Technologies:** HTML5, CSS3, Bootstrap 5, JavaScript, Bootstrap Icons, Google Fonts.
